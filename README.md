## 👋 Hi there

I'm a Cybersecurity Engineering  — specializing in **SOC operations**, **Digital Forensics & Incident Response (DFIR)**, and **post-quantum cryptography**.

I don't just study security — I build tools, write detailed technical breakdowns, compete in CTFs, and contribute to open-source projects that solve real detection and response challenges.

- 📝 Published in [InfoSec Write-ups](https://infosecwriteups.com), [OSINT Team](https://osintteam.blog), [System Weakness](https://systemweakness.com), [CodeToDeploy](https://medium.com/codetodeploy), [MeetCyber](https://meetcyber.net)
-  Career path: **SOC Analyst → Threat Intelligence Engineer → Security Researcher**
